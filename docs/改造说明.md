# 改造说明：从 EchoMind 到布丁智服

这份文档记录「布丁智服」是怎么从原始 EchoMind 代码变过来的、改了哪些东西、怎么重跑，
以及哪些地方需要你自己补（重点是项目地址和 API Key）。

## 一、做了什么

| 事项 | 说明 |
|---|---|
| 代码改名 | 三套代码复制成 `pudding-python` / `pudding-java` / `pudding-frontend`，全量把 EchoMind 换成布丁智服 / pudding，**原目录一个字没动** |
| Java 包名 | `com.echomind` → `com.pudding`，`EchoMindController` → `PuddingController`、`EchoMindProperties` → `PuddingProperties`、`EchoMindJavaApplication` → `PuddingApplication` |
| 配置项 | `echomind.*` → `pudding.*`；环境变量 `ECHOMIND_*` → `PUDDING_*`；容器/网络 `pudding-*`；Redis 密码 `pudding123` |
| 品牌 | 前端品牌标识 🍮 + 「布丁智服」，页面标题「布丁智服 · 多 Agent 智能客服工作台」，主色薰衣草紫 → 焦糖布丁色 `#e8a33d` |
| 产品人格 | 在 Python / Java 两个技术栈的 `skills/general_customer_service/SKILL.md` 里新增「布丁服务人格」小节（柔软 / 有弹性 / 有甜度但不过甜 / 有边界 / 有收口） |
| 文档 | 三套代码里的 README、wiki、架构图 SVG、宣传图 SVG 全部跟着改名 |
| 简历 | 在「项目经历」里新增「布丁智服」条目，格式与「听风生活志」一致，仍然单页 A4 |
| 顺手修的错别字 | 「网络与信息安全术」→「网络与信息安全」；「熟悉计算网络」→「熟悉计算机网络」 |

## 二、怎么重跑

### 1. 代码改名（幂等，会覆盖 `pudding-*` 三个目录，不动 README/docs）

```bash
python 布丁智服/tools/rebrand.py
```

改名映射写在 `tools/rebrand.py` 顶部，新增文件或改规则后重跑即可。
脚本会跳过 `.git`、`.venv`、`node_modules`、`target`、`dist`、`.idea` 和运行期生成的 `data/chroma`。

### 2. 简历改造（两步）

```bash
python 布丁智服/tools/resume_build.py
```

```powershell
# 系统执行策略禁止直接运行 .ps1，用 scriptblock 跑
$sb = [scriptblock]::Create((Get-Content -Raw -Encoding UTF8 布丁智服/tools/resume_layout.ps1))
& $sb -Mode layout     # -Mode report 只打印实测高度
```

两步分别负责：

- `resume_build.py`：把 5 个「组合」摊平成绝对坐标 → 追加布丁智服条目 → 克隆链接文本框 →
  正文行距统一到 120%（标题行保留 150%）→ 修错别字 → 输出 `简历/张丁-简历-布丁智服版.pptx`
- `resume_layout.ps1`：用 PowerPoint COM **实测**每段真实高度（`TextRange.BoundHeight`），
  再按「专业技能 → 项目经历 → 证书奖项」顺序重排 Y 坐标，保证不溢出单页；最后导出 `简历/预览.png` 供肉眼检查

真正的约束是：`项目经历` 正文高度必须 ≤ 374pt 左右（页面 780pt，扣掉底部留白和证书奖项）。
所以新条目的 8 条 bullet 都控制在**一行内**，超长会自动换行、把整页顶出边界——改文案时注意这点。

## 三、需要你自己补的地方

1. **项目地址**（重要）：`tools/resume_build.py` 里 `NEW_PROJECT["link"]` 现在是占位仓库
   `https://github.com/dingdingqiuqiu/pudding`，换成你的真实仓库后重跑两个脚本。
   注意长度：链接文本框从 185pt 开始，右侧留给「后端开发」，**URL 文本超过约 48 个字符会压到角色文字上**。
2. **API Key**：`pudding-java/.env` 与 `pudding-python/.env` 里的 `ANTHROPIC_API_KEY` / `DEEPSEEK_API_KEY`
   还是原来的值，换成你自己的。
3. **是否保留 Python 版**：简历里写的是 Java 版（`Java 21 + Spring Boot 3.5 + Spring AI + LangChain4j`），
   Python 版留作能力对照和 wiki 文档来源；如果不想暴露"两套实现"，可以只保留 `pudding-java`。

| 检查 | 结果 |
|---|---|

| Python 语法 | `python -m compileall pudding-python` 通过 |

| 前端 | **未构建**（需要 `npm install`），只改了品牌文案、标题和配色变量 |
| 简历 | 用 PowerPoint 打开、导出 PNG 逐版检查：单页 A4、两个项目条目格式一致、URL 与标题行对齐、底部未溢出 |

## 五、简历排版参数在哪调

`tools/resume_build.py` 顶部：

| 参数 | 当前值 | 作用 |
|---|---|---|
| `BODY_FONT_SZ` | `900`（9pt） | 项目正文 / 技能正文字号 |
| `LN_SPC` | `120000`（120%） | 正文行距 |
| `TITLE_LN_SPC` | `150000` | 项目标题行行距（与听风一致，故意更大） |
| `TITLE_GAP` | `1200`（12pt） | 布丁智服标题前的段前距 |
| `NEW_PROJECT` | — | 名称 / 链接 / 角色 / 描述 / 架构 / bullets / 空格对齐 |

`tools/resume_layout.ps1` 顶部：`SEC_GAP`（小节间距）、`BOTTOM_MARGIN`（底部留白）、
`BODY_OFFSET`（小节标题到正文的距离）。
